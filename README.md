“师大课程表”安卓APP出炉了！
大家应该用过W某Up或星某课表之类的课程表软件。但是开发者逐渐忘记初心，往更新后的应用里塞入了大量广告和收费功能，以及没啥用的功能（比如课程表应用内集成搜题？wtf），让软件臃肿不堪。为此，我借鉴并开发了专属于CWNU的课程表软件——“师大课程表”！它拥有高度自定义的可玩性和绝对安全的数据储存能力等，并且我承诺绝对无广告、无收费，包括今后可能的更新，都不会有收费和广告。非常小的安装包（只有约4MB），安装之后占用空间如图。并且UI使用纯正的Material Design 3，保证应用美学和流畅。小组件也准备了四种规格，如图所示。  
【核心功能】
1. 西华师大教务一键导入
   打开应用→首次启动向导→教务系统导入→输入学号密码登录→自动获取课表。仅需一次登录，课程数据全部保存在手机本地，不上传任何服务器，绝对安全。
2. 周课表 + 今日课表
   底部导航栏切换本周课表和今日课表。支持显示/隐藏周末、显示/隐藏非本周课程，可自由调整。当前周高亮，已结课周次自动置灰。点击课程卡片查看详情（教师、教室、周次）。
3. 冬夏作息自动切换
   10月1日至次年5月1日自动应用冬季作息，其余时间自动切换夏季作息。无需手动调整，开学即用。当然你也可以手动选择预设。
4. 高度自定义主题
   支持浅色/深色/跟随系统三种模式，支持动态取色（Material You壁纸取色），支持自定义种子色。全局 Material Design 3 Expressive 风格，按钮弹性、导航动画流畅。
5. 四种桌面小组件
   提供迷你（1×1）、紧凑（2×1）、双日（2×2）、列表（3×2）四种规格的桌面小组件，可放置在桌面随时查看当天和本周课程，无需打开应用。
6. 课表文件导入/导出
   支持 JSON 格式课表文件导入导出，可备份/恢复完整课表数据（含课程、作息、配置）。支持 ICS 日历文件导出，可同步到系统日历。
7. 课程提醒
   支持课前提醒（可自定义提前分钟数），自动模式（静音/免打扰），兼容穿戴设备同步提醒。  
【安全保障】  
- 所有数据存储在手机本地（Room 数据库 + DataStore），无任何网络上传
- 教务登录仅在 WebView 内完成，应用不接触你的密码
- 开源代码可审查（Apache 2.0 协议）

【常见问题】  
Q：为什么安装包这么小？  
A：使用 Kotlin Multiplatform + Compose Multiplatform 原生开发，R8 代码混淆压缩，无冗余功能。  
Q：会不会有广告？  
A：不会。作者承诺：永久无广告、无收费。这是写给所有师大兄弟姐妹们的软件，不是写来赚钱的。

A：不支持。本应用仅支持 Android。后期也可能会适配iOS和HarmonyOS（作者是穷苦大学生，买不起iPhone，呜呜呜
